      Password vs passphrase

      A long, unique passphrase of randomly chosen words is easier to remember than x7$Qp!2z and hard to guess. Never use quotes or song lyrics. Examples such as velvet-galaxy-harbor-orchid are for demonstration only: do not reuse them.

      Why Password123! is weak

      It satisfies composition rules but is a common word + predictable number + symbol. Length + unpredictability + pattern resistance + common-password checks + context give a better assessment.

      10 password security rules

      1. Use a unique password for every account.
      2. Prefer long passwords or passphrases.
      3. Avoid predictable personal information.
      4. Avoid common passwords.
      5. Never reuse passwords across sites.
      6. Use a password manager.
      7. Enable MFA.
      8. Never share passwords.
      9. Be cautious of phishing pages.
      10. Change passwords when a compromise is suspected or confirmed.

      Entropy ≈ L × log₂(N) assumes random choice, so it is optimistic for human-made passwords. Scores are project-defined, not a universal standard.
